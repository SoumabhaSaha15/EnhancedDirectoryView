> # ![icon](./public/icon/24.png) EnhancedDirectoryView

> ## Tailwind + DaisyUI based project that overrides the native styles of existing browsers folder view

> ![preview](/screenshots/preview.png)

> ## Installation 

```txt
  Instal the zip file.
  Unzip it and turn on developer mode on the browser extension manager.
  Load unpacked and select the dist folder. 
```
